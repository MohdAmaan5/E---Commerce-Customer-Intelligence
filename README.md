📌  Overview

This is an E-commerce customer intelligence project, the analysis of this project is performed on Jupyter notebook python and MySQL, the analysis of this project was done using python libraries like numpy and pandas on jupyter notebook and SQL queries on MySQL, the process from loading the dataset till cleaning the dataset was done via python, KPI analysis and EDA was performed through SQL queries. Power BI was for data visualisation. Lastly a report was concluded of the found insights.

📁 Dataset

* Description : Customer behavior and trend patterns.
* Type : database
* Size : 407 kb
* Source : Google

🛠 Tools and Tech

* Microsoft Excel : used to check the format of the data
* Python (Numpy, Pandas) : Used for the data cleaning, handling.
* SQL : Used to perform exploratory data analysis.	
* Microsoft Power BI : used for data visualisation.
* Microsoft Word : used for report writing.

📋 Steps performed  

1. Data (Loading or Importing) : At first the dataset was loaded in Jupyter notebook using python functions.

2. Data (Overview, Cleaning, Analysis) : Further data cleaning and basic handling was performed on Python then afterwards the analysis was done using SQL queries.

3. Data (Exporting and Visualisation) : After all the analysis then data was transported to Microsoft Power BI for dashboard creation.

4. Report Writing : Finally a summary report was concluded on Microsoft Word for business strategies and decisions.
